# PAMILANGA EVIDENCE

**Evidence Infrastructure for Physical AI**

> Autonomous systems can make decisions. We make those decisions provable.

PAMILANGA EVIDENCE is an independent evidence infrastructure project for reconstructing, reproducing, and proving Physical AI decision chains.

## v0.1 architecture

TRACE → REPLAY → PROVE → ASSURE

Technical chain:

Capture → Provenance & Temporal Integrity → Evidence Graph → First Divergence → Causal Hypotheses → Deterministic / Counterfactual Replay → Evidence Sufficiency → Evidence Object

## Current status

- M0 — Product Thesis & Architecture Freeze: **FROZEN**
- M1 — TRACE: **in development**

## Project boundary

PAMILANGA EVIDENCE is developed independently from the frozen PAMIR v0.1, PAMIR-CUAS, PAMIR ARGUS, and PAMIR IGNIS baselines. Validated concepts may be reused only through explicit interfaces and provenance boundaries.

## v0.1 objective

Deliver a working demonstrator, reproducible validation, Evidence Pack, and product surface. Capability claims are limited to implemented and validated behavior.
